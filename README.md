# hf-space-cloner
Clone spaces on hugging face easily 🤗. "Open?" may not work. So input instead "n"

# How to run
You need git installed to clone.
```cmd
  git clone https://github.com/ScratchTheCuriousCat/hf-space-cloner.git
```
Then run:
```cmd
  cd hf-space-cloner
```
Now, to start the program, run:
```cmd
  python cloner.py
```
